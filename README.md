# Advanced Python Time-Series Analysis on Apple (AAPL) Stock Data

## Project Overview

This project was completed as part of the AnalystLab Africa Week 6 Internship Task on Advanced Python Analysis.

The project focuses on analyzing historical Apple Inc. (AAPL) stock market data using Python, Pandas, and time-series analysis techniques. The analysis explores stock price trends, daily performance, moving averages, monthly returns, trading volume, and volatility.

## Objective

The objective of this project is to apply advanced Python techniques for data transformation, time-series analysis, and feature engineering using historical stock market data.

## Dataset

The dataset contains historical stock market information for Apple Inc. (AAPL) obtained from Yahoo Finance.

### Dataset Features

- Date
- Open Price
- High Price
- Low Price
- Close Price
- Adjusted Close Price
- Trading Volume

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- Jupyter Notebook

## Analysis Performed

### Data Loading and Exploration

- Loaded historical AAPL stock data using yfinance
- Examined the dataset structure
- Checked data types
- Checked for missing values
- Reviewed summary statistics

### Data Cleaning and Transformation

- Converted the Date column to datetime format
- Set Date as the time-series index
- Checked and handled missing values
- Sorted the dataset chronologically
- Prepared the data for time-series analysis

### Feature Engineering

The following features were created:

- Daily Price Change
- Percentage Price Change
- 7-Day Moving Average
- 30-Day Moving Average
- Monthly Returns
- 30-Day Rolling Volatility

## Time-Series Analysis

The project analyzes:

- Historical closing price trends
- Daily price movements
- Trading volume patterns
- Monthly stock returns
- Short-term and long-term moving averages
- Rolling volatility

## Visualizations

The project includes visualizations covering:

- AAPL Closing Price Trend
- Trading Volume Trend
- Moving Average Analysis
- Monthly Returns
- Additional time-series patterns

These visualizations help identify trends, changes in stock performance, trading activity, returns, and volatility over time.

## Key Findings

The analysis identified important patterns in Apple's historical stock performance.

The closing-price analysis shows how AAPL's stock value changed over the selected period, while the moving averages help identify broader price trends.

Daily and monthly return analysis provides insight into periods of positive and negative performance. Trading volume analysis highlights changes in market activity, while rolling volatility helps identify periods of greater price fluctuation.

For detailed findings and recommendations, see the Insight Summary included in this repository.
